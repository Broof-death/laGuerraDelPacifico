# Referencias de estética (1879–1894)

Imágenes de época para uniformes, buques, ciudades y ambiente. Las usa la guía [`docs/diseno/estilo-visual.md`](../../diseno/estilo-visual.md). No son parte del juego: `docs/` tiene `.gdignore`.

**Derechos.** Todas están en Wikimedia Commons como dominio público (DP), «sin restricciones de copyright conocidas» (NKC, British Library) o con licencia libre (CC BY-SA, que exige citar al autor y compartir igual). Los datos de autor, fecha y fuente son los de la ficha de Commons. Algunas fichas de Commons tienen una procedencia débil (un blog o un foro como fuente); se indica en la columna de notas y conviene buscar la copia de la institución antes de usarlas para algo más que referencia.

**Las fotos son en blanco y negro**: sirven para formas y siluetas, no para colores.
